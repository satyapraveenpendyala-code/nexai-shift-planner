# SOP-OSF: Overstrain failure

## 1. When this applies
Use this procedure when the predicted failure mode is overstrain. In the AI4I data, overstrain occurs when tool wear multiplied by torque (strain) exceeds 11000 min·Nm for type L, 12000 for type M and 13000 for type H machines.

## 2. Safety
Stop the machine and apply lockout/tagout before touching the tool or spindle. Confirm the spindle has fully stopped and the machine cannot be restarted.

## 3. Inspection
Read the current tool wear and torque values and compute strain against the limit for the machine type. Inspect the tool for chipping, deformation or excessive wear, and check the torque limiter for signs of tripping.

## 4. Corrective action
Replace the worn tool to reset its wear, which brings strain (min·Nm) well below the overstrain limit for the machine type (L, M or H). If torque (Nm) stays high on the new tool, reduce the cutting load or feed and report the job settings to the shift supervisor.

## 5. Restart check
Remove lockout/tagout only after all tools and people are clear. Run the machine under normal load and confirm torque times tool wear stays below the type limit.
