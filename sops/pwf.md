# SOP-PWF: Power failure

## 1. When this applies
Use this procedure when the predicted failure mode is power. In the AI4I data, power failure occurs when power, computed as torque times rotational speed in rad/s, is below 3500 W or above 9000 W.

## 2. Safety
Stop the machine and apply lockout/tagout at the electrical isolator before inspecting the drive. Only qualified electrical staff may open drive or supply panels.

## 3. Inspection
Read the torque and rotational speed and compute power to see whether it is below 3500 W or above 9000 W. Check the drive, supply connections and any drive fault codes.

## 4. Corrective action
If power (W) is above 9000 W, reduce the load, torque (Nm) or speed (rpm) so power returns to the normal band. If power is below 3500 W, check for a weak supply or slipping drive and correct it, or escalate to the shift supervisor if the cause is not found.

## 5. Restart check
Remove lockout/tagout only after panels are closed and the area is clear. Run the machine and confirm power stays between 3500 W and 9000 W.
