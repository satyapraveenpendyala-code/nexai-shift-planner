# SOP-TWF: Tool wear failure

## 1. When this applies
Use this procedure when the predicted failure mode is tool wear. In the AI4I data, tool wear failures typically happen when tool wear is above about 200 minutes, but the exact point is partly random, so treat this prediction as low confidence.

## 2. Safety
Stop the machine and apply lockout/tagout before removing or handling the tool. Wear cut-resistant gloves when handling worn tools.

## 3. Inspection
Check the tool wear counter and the wear log for this machine. Visually inspect the tool insert for flank wear, chipping or breakage.

## 4. Corrective action
Replace the tool insert if tool wear is above about 200 minutes or visible damage is found, and reset the tool wear counter. If the tool looks fine and wear is low, record the inspection and escalate to the supervisor, since the prediction may be a false alarm.

## 5. Restart check
Remove lockout/tagout only after the area is clear. Run a short test cycle and confirm the wear counter has been reset in the log.
